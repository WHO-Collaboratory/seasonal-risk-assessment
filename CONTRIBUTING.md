# Contributing

Thank you for your interest in the WHO Seasonal Risk Assessment Tool for Acute Emergencies.

## Using this tool

Filling out the workbook with your own emergency data and running the Shiny app as provided is the intended use of this tool, and requires no attribution or license action on your part.

## Adapting this tool

The **source code** is released under the **MIT license**. You are welcome to fork this repository and modify the workbook structure, the underlying methodology, or the application code for a different context or emergency type. The **Excel workbook** and its embedded guidance are released separately under the **CC BY-NC-SA 3.0 IGO license**; if you adapt the workbook itself (rather than filling it out), remove the WHO emblem from the Instructions tab and include the adaptation disclaimer described there.

## Reporting issues

The workbook and the Shiny app are built to work together and depend on a fixed set of sheet names and column headers. If you find a bug, or a change to one component would affect the other, please open an issue describing it rather than submitting a pull request directly. This lets us weigh the effect on both components before anything changes.
